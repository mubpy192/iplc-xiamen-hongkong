## 厦港 IPLC 是一条什么线路

先说清楚这条线的构成。厦港 IPLC 的入口在厦门，接的是动态 BGP；出口在香港，同样是 BGP。它属于 MKCloud 福建到香港的高防 IPLC 产品系列，同系列还有一个兄弟产品泉港专线，入口在泉州电信。

几个核心参数，直接来自官方产品页：

- 端内参考延迟 **1~2ms**，是目前 MKCloud 全线产品里延迟最低的档位之一（广港 IEPL 也是 1~2ms）
- 每台机器分配 **2 个独享 IPv4**，一个入口 IP、一个出口 IP
- 默认含 **100Gbps 高防**，防御可定制升级，可申请开通无视海外攻击与 UDP 攻击
- 无跨省 QoS 限制，无省份限制
- 流量无限制，按独享带宽计费

这里要解释一下“端内延迟”这个概念，因为它经常被误解。1~2ms 指的是厦门入口到香港出口这段专线内部的延迟，不是你家里宽带到目标网站的全程耗时。你本地的宽带质量、香港出口之后的国际路由，都会叠加在最终体验上。官方知识库也明确提醒了这一点，选购时别把端内值当成全程延迟预期。

## 购买前必须知道的几个限制

这部分比价格更重要，都是官网和知识库明确写着的规则，下单前过一遍能省很多售后麻烦。

**出口 IP 不支持外部连入。** 你通过入口 IP 连上去操作，程序自动从香港出口向外访问，但出口不能被外部主动连进来。也就是说，这台机器不能当公开网站服务端、游戏服务端或者外部回调的落点。它适合的是“从国内主动向外跑业务”的方向，比如电商运营、数据同步、访问海外平台。

**退款只认质量问题。** 官方政策是仅支持质量问题退款，且需要你在工单里提交具体证据——准确的延迟数据、速度数据，由 MKCloud 审核判断。不是无条件试用。开通后也不支持更换到其他地域的产品。所以下单前先想清楚线路方向对不对。

**升降级要走工单。** 套餐升降级不是后台点一下就完事，需要提工单操作，而且降级到更低价格套餐时差价不退。

**默认无 SLA。** 高防不等于容灾，海缆故障可能导致中断，多个海外运营商出口也不代表跨境段有独立备份。需要明确保障承诺的，官方建议先走定制沟通。

## 适合谁买，不适合谁

基于上面的参数和限制，这款产品的适用面其实很清晰。

适合的情况：业务主体在福建或华南、对香港出口有低延迟要求；业务容易被 DDoS 打（游戏私服、金融接口、大促期间的电商站群）；需要独享带宽而不是共享峰值；预算上每月几千到几万不构成压力。

不适合的情况：只是想找一台便宜的香港 VPS 建站——出口不能外部连入直接否掉这个用途；预算在一两百一个月的量级——同家的深港 IX 和沪港 IPLC 更合适；没有中国身份信息完成实名——这条是硬门槛。

如果拿不准哪一档够用，官方页面所有配置都支持定制，也可以先从 [👉 厦港 IPLC 产品页](https://bit.ly/MKCLoud) 确认当前库存和报价再决定。200M 档是否现货会随库存波动，页面上实时状态比任何评测文章都准。

## 常见问题

**厦港 IPLC 的 1~2ms 是我上网的延迟吗？**
不是。这是专线内部（厦门入口到香港出口）的参考延迟。你的实际体验还要加上本地宽带到入口、香港出口到目标网站的耗时。

**能跑满标称带宽吗？**
独享带宽意味着带宽资源归你独占，但官方知识库明确说了“不限流量不等于无限速”，应用速度还受服务器性能、目标服务和协议影响，不承诺任何时刻跑满。

**支持退款吗？**
仅支持质量问题退款，需要在工单里提交延迟、速度等具体数据作为证据。开通后不能换地域。

**可以用它建网站对外提供服务吗？**
不可以。出口 IP 不支持外部连入，不能作为公开网站、游戏服务端或回调入口。

**怎么付款？**
目前只支持支付宝，需要中国身份信息实名。
